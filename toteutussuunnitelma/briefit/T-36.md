```
  WHERE polku = 'peili' AND id >= '<tiedosto>:' AND id < '<tiedosto>;'      (';' = ':' + 1)
Offset-järjestys: id-järjestys ei ole numeerinen ("f:10" < "f:9") → järjestä offsetin mukaan haun jälkeen (kuten nyt).

```
