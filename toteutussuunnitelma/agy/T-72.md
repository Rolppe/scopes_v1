# agy-ohje T-72 — ARK-18:n hyväksyntäajo (macOS-äpin näyttö hereillä)

Lue ensin [README.md](README.md): yhteiset säännöt, kielletyt komennot ja pysähtymisohje. Ne koskevat tätäkin ohjetta.

**28.10.2026 (vaihe 3, toteutussuunnitelma):** aloitus on README:n vakioaloitusprompti (`<T-NN>` = `T-72`, worktree `~/sessions-repo-t72`). Tee README:n Preflight (rivit 1–8; rivit 4 ja 5 näyttölukolla) ennen alla olevaa tarkistusta, ja lähetä ALOITUS-viesti. Jokainen **STOP** tässä ohjeessa lähettää myös PYSÄHDYN-viestin (README, "Viestinvaihto"). Commitoitavaa ei ole (valvoja-ajo). Kaikki portit ovat Apple-portteja (`scopes2/shared/gate.sh`), joten ne ajetaan Macilla.

## Mitä tämä on

Valvoja-ajo. Agy ei muuta koodia eikä committaa. Ajo todentaa, että macOS-äppi ScopesV2Mac pitää näytön hereillä, kun se käynnistetään argumentilla `-scopes2.naytto-hereilla YES` (T-71, commit 3b199453), ja että macOS-UI-testit eivät enää tarvitse `caffeinate`a. Lähde: `scopes/toteutussuunnitelma/SUUNNITELMA.md`, luku 11.7, rivi `| T-72 |`.

- Ajopaikka: Mac, käyttäjä `mikko`.
- Ajava skooppi: `scopes2 shared` (T-71:n omistaja) tai se, jonka koordinaattori nimeää.
- Kesto: osa A noin 10–20 min. Uudessa worktreessä XCFramework käännetään ensin, ja siihen menee lisäaikaa. Osa B 5–40 min (T-49 kesti 21.10. 294 s ja 20.10. 2420 s).
- Raporttikansio: `$HOME/agy-raportit/T-72/`.

## Toteutussuunnitelman tarkennukset 21.10.2026 (Opus 5.5, lähteestä)

Nämä korvaavat suunnitelmarivin sanamuodon tässä ajossa.

1. **Kohta (4):** suunnitelmarivi vaatii, että `grep -rn caffeinate …` on tyhjä. Tiedostossa `scopes2/shared/testit/KaksiLaitettaUITests.swift:118` on kuitenkin kommenttirivi (`// T-71: … ilman ssh-caffeinatea …`), joten tyhjä tulos ei ole mahdollinen. Hyväksytään, kun mikään muu kuin kommenttirivi (`//` tai `#`) ei mainitse `caffeinate`a.
2. **Kohta (2):** suunnitelmarivi vaatii, että `pgrep -x caffeinate` on tyhjä. Macilla on kuitenkin aina Claude Coden omia prosesseja `caffeinate -i -t 300`, joiden vanhempi on `claude` (mitattu 21.10. klo 17.35, 7 kpl). Ne estävät vain järjestelmän uneen menon, eivät näytön sammumista. Hyväksytään, kun ajon aikana ei näy muuta `caffeinate`a kuin `caffeinate -i -t 300`, jonka vanhempi on `claude`.
3. **Näytön lukitus:** `sysadminctl -screenLock status` antoi 21.10. klo 17.35 tuloksen `screenLock delay is immediate`, eli näyttö lukittuu heti sammuessaan. Lukittua näyttöä äpin kytkin ei avaa (K-11). Siksi osa B (kohdat 2 ja 3) ajetaan vain käyttäjän ollessa Macin ääressä. Lisäksi Awake-äppi pitää näytön hereillä (`PreventUserIdleDisplaySleep`). Sitä ei suljeta, vaan se kirjataan raporttiin.

## Osa B — käyttäjä paikalla: kohdat (2) ja (3)

### B1. Lukko ja tila

```
lockf -t 0 "$HOME/scopes2-lukot/naytto.lukko" true; echo EXIT=$?
```
Odotettu: `EXIT=0`. Jos tulos on `EXIT=75`, toinen macOS-UI-ajo on käynnissä. Näytön sammuttaminen kaataisi sen, joten **STOP** ja kerro käyttäjälle.

```
pgrep -fl ScopesV2Mac; echo EXIT=$?
```
Odotettu: ei tulosrivejä ja `EXIT=1`. Jos rivejä tulee, jokin muu ScopesV2Mac on käynnissä samalla bundle-id:llä, ja XCUI-testiäppi jää tilaan "Running Background" (21.10.2026 uusinta). **STOP** ja kerro käyttäjälle prosessi; älä sulje sitä itse.

### B2. Näyttö pois, käyttäjä avaa lukituksen, sitten T-49 ilman `caffeinate`a

Korjattu 21.10.2026 (toteutussuunnitelma): arkkitehtuurin ARK-18-hyväksyntä on "T-49 vihreä näytön oltua sammuneena (avattuna)". Lukitun näytön aikana XCUI ei saa äppiä aktiiviseksi (uusinta 19.36–19.43: `LOCKED=1` 22/23 näytteessä, kaikki macOS-UI-testit "Failed to activate application"). Siksi portti käynnistyy vasta, kun käyttäjä on avannut lukituksen.

B2a. Kirjoita ensin ruutuun: `Sammutan näytön 3 sekunnin päästä. Odota 30 s, herätä näyttö näppäimellä ja avaa lukitus.` Aja sitten:

```
sleep 3 && pmset displaysleepnow && sleep 30; echo EXIT=$?
```
Odotettu: `EXIT=0`.

B2b. Odota, että lukitus on auki (enintään 5 min). Komento tulostaa `AUKI` tai `LUKOSSA` aikakatkaisun jälkeen:

```
for i in $(seq 1 60); do ioreg -n Root -d1 | grep -q '"CGSSessionScreenIsLocked"=Yes' || { echo AUKI; break; }; sleep 5; done; ioreg -n Root -d1 | grep -q '"CGSSessionScreenIsLocked"=Yes' && echo LUKOSSA
```
Jos tulos on `LUKOSSA`, **STOP** ja kerro käyttäjälle, että lukitus on yhä kiinni.

B2c. Aja yksi komento. Se ajaa portin T-49 ja kirjaa 15 s välein lukkotilan, `PreventUserIdleDisplaySleep`-väitteiden määrän sekä jokaisen `caffeinate`-prosessin komentorivin ja vanhemman nimen.

```
cd ~/sessions-repo-t72 && ( while true; do date +%H:%M:%S; ioreg -n Root -d1 | grep -q '"CGSSessionScreenIsLocked"=Yes' && echo LOCKED=1 || echo LOCKED=0; pmset -g assertions | grep -E '^ +PreventUserIdleDisplaySleep'; for p in $(pgrep -x caffeinate); do echo "$(ps -o args= -p $p) | $(ps -o comm= -p $(ps -o ppid= -p $p))"; done; sleep 15; done > "$HOME/agy-raportit/T-72/caffeinate-naytteet.txt" 2>&1 & echo $! > "$HOME/agy-raportit/T-72/naytteistin.pid" ) && bash scopes2/shared/gate.sh T-49 > "$HOME/agy-raportit/T-72/t49.log" 2>&1; echo EXIT=$?; kill "$(cat "$HOME/agy-raportit/T-72/naytteistin.pid")"
```
Odotettu: `EXIT=0`, ja lokin viimeinen rivi on `PORTTI VIHREÄ: T-49`.
